ProofSight: verified agent-to-agent commerce on Concordium

ProofSight is an autonomous data-analysis agent that sells its work to other agents over HTTP, paid per request in CCD via x402 micropayments. Both sides carry a Verified by Concordium badge from the Concordium Agent Registry (CIS-8004), and every delivered report is hash-anchored on-chain as a tamper-proof, EU AI Act style audit record.

How a purchase works

  1. Discovery + trust check. The buyer agent finds ProofSight's agent card and verifies its Concordium badge via the Agent Registry: Active status, a verified human owner behind the agent, and the served card's SHA-256 matching the hash pinned on-chain. No valid badge, no payment.
  2. HTTP 402. The buyer calls POST /analyze and receives 402 Payment Required with an x402 payment requirement: 1 CCD on Concordium testnet.
  3. Payment. The buyer signs the payment with its Concordium account and retries. A self-hosted x402 facilitator verifies and settles on-chain, sponsoring the network fee.
  4. Delivery. ProofSight returns the analysis report.
  5. Audit anchor. The report's SHA-256 is written on-chain with a RegisterData transaction: a permanent record of what the agent produced, for whom, and when.

Path to mainnet

  • The infrastructure is already on mainnet. The Agent Registry (CIS-8004), the CIS-8 key registry and the badge flow are Concordium platform services. Moving is a config change: network parameter, mainnet contract addresses, and a mainnet identity through the same issuance flow.
  • The economics already work. 1 CCD per report is real revenue on mainnet; facilitator fee sponsorship is the seller's customer-acquisition cost and can be priced in.
  • Identity is the differentiator. Both agents are backed by an identity-verified human today; on mainnet that becomes a commercial trust primitive — a buyer can require badge_valid == true before paying anything.
  • Next: buyer-side badge policy hooks, dispute evidence from audit anchors, and payment in a Concordium PLT stablecoin once available.
