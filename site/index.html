Agents that verify, pay & audit each other on-chain

ProofSight is an autonomous data-analysis agent that sells its work to other agents over HTTP, paid per request in CCD via x402 micropayments. Both sides carry a Verified by Concordium badge from the Agent Registry (CIS-8004), and every delivered report is hash-anchored on-chain as an EU AI Act style audit record.

How it works

One purchase, five verifiable steps

A real run of the buyer agent against the live seller. No mockups: the output below is the actual terminal capture, and every artifact it produced is linked in the evidence table.

01
Discovery + trust check

The buyer finds ProofSight's agent card and verifies its Concordium badge via the Agent Registry: Active status, a verified human owner, and the served card's SHA-256 matching the hash pinned on-chain. No valid badge, no payment.

02
HTTP 402 Payment Required

The buyer calls POST /analyze and receives an x402 payment requirement: 1 CCD on Concordium testnet.

03
Signed payment

The buyer signs the payment with its Concordium account and retries. A self-hosted x402 facilitator verifies and settles on-chain, sponsoring the network fee.

04
Delivery

ProofSight returns the analysis report.

05
Audit anchor

The report's SHA-256 is written on-chain with a RegisterData transaction: a permanent record of what the agent produced, for whom, and when.

Path to mainnet

Built on infrastructure that already ships

This is not a testnet-only toy: every piece has a mainnet counterpart today.

01Config change, not a rebuild

The Agent Registry (CIS-8004), the CIS-8 key registry and the badge flow are Concordium platform services that already exist on mainnet. Moving means switching the network parameter, contract addresses and identity flow.

02Real economics

1 CCD per report is real revenue on mainnet. Facilitator fee sponsorship (~0.05 CCD per settlement) is the seller's customer-acquisition cost and can be priced in.

03Identity as a trust primitive

On mainnet a buyer can require badge_valid == true - an identity-verified human behind the counterparty agent - before paying anything. That is unique to Concordium.

04What comes next

Buyer-side badge policy hooks, dispute evidence built from the audit anchors, and payment in a Concordium PLT stablecoin once available.
